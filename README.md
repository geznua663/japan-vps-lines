## 先确认你的用户在哪，再谈线路

很多人第一步就去比带宽数字，这顺序是反的。

日本节点最舒服的场景，其实比"日本"这个标签窄一些：

- 主要用户在华北、华东，或者你的访客里联通占比高
- 需要免备案、又要比香港便宜一些的亚洲节点
- 业务对带宽敏感，比如下载、图床、流媒体、内容分发
- 需要日本本地 IP 做日区业务、日淘、日服游戏、日区平台账号

如果你的核心用户主要在华南，而且清一色电信，香港节点很多时候确实更直接。这个判断不用纠结情怀，物理距离决定的下限摆在那儿。

## 东京的几条线路，差别比"东京"本身大

同一个东京机房，不同运营商出来的体验差距，可能比东京和大阪之间还大。市面上常见的是这么几类：

**CN2（电信优化）**——在中国电信网络里有更高优先级，晚高峰不容易被挤掉。日本线路里常见的形态是去程走普通国际出口、回程走 CN2，也就是常说的"CN2 回程"。这类方案对电信用户最友好。

**软银 / SoftBank**——联通用户的体感往往比 CN2 还好，带宽给得宽，白天拉文件很痛快，更适合下载和流媒体这类吃带宽的场景。

**IIJ**——便宜、带宽大，白天测速经常很漂亮，但晚高峰稳定性的波动概率更高一些。做测试和学习环境没问题，当正式线上入口就得先多测几轮。

**普通 BGP 国际线路**——成本最低，代价是高峰期可能绕路，延迟从 80ms 直接跳到 200ms。

判断线路不靠宣传页，靠测试 IP。下单前先要一个测试 IP，本地跑一遍 `mtr` 或者 `traceroute`，看回程都经过哪些节点。这一步花十分钟，比看十篇测评管用。

## 挑日本VPS最容易踩的四个坑

**假 CN2。** 有的商家页面上写 CN2 GIA，实际 CN2 只到上海，上海到东京那段走的是普通 163，晚高峰照样堵。识别方法还是看路由。

**非原生 IP。** 普通 IP 和原生 IP 对建站影响不大，但如果你要用 TikTok、日区电商后台、日本本地支付类服务，IP 归属地就是生死线。买之前必须问清楚。

**流量计费方式。** 这是最容易忽略的成本项。有的套餐是双向计费——上传和下载单独算，跟你理解的"流量"完全是两回事，业务一跑起来额度掉得飞快。

**IP 费用另算。** 不少商家的套餐价是不含 IPv4 的，一个 IP 再收 5 元、10 元。看价格时要把这块加进去。

## 常见问题

**日本东京节点需要备案吗？**
不需要。海外节点免备案，域名解析完就能上线，适合快速验证项目或者临时业务。

**CN2 回程到底有什么用？**
CN2 是中国电信网络里优先级更高的一类线路，在高峰期更不容易被挤掉。体现在体感上，就是别家开始掉包的时候你还能正常访问。实测平均延迟在 70ms 上下，属于日本节点的正常水平。

**有限流量和无限流量怎么选？**
看你的业务是"瞬时带宽吃紧"还是"总流量吃紧"。前者选有限流量版，入门档就能拿到 20Mbps 上行、40Mbps 下行；后者选不限流量版，但带宽会降到 5Mbps 起。价格完全一样，等于用带宽买额度。

**流量用超了会怎样？**
不会断网，会被限速（不同区域和套餐限速档位不同，从 1Mbps 到 5Mbps 不等），想恢复高速就单独买流量包。另外有限流量套餐的结余流量会自动叠加到下个月，不清零，这点对流量波动大的用户比较友好。

**支持 Windows 吗？**
支持，Linux 和 Windows 都可以装，部分地区还可以选 macOS。

**能装宝塔或者 Docker 环境吗？**
可以，官方提供预装应用和环境镜像，包括宝塔、1Panel、Docker、MCSManager 等，也能用自定义镜像。

**最低多少钱能用上？**
极速三网入门档 33 元/月，软银大带宽入门档 25 元/月（不含 IP 费用）。如果用首月 5 折券，第一个月的实际支出还会更低。
